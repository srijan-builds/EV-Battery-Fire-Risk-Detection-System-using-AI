🚗🔋 **EV Battery Fire-Risk Detection System with AI Risk Prediction**

Developed as a smart battery safety and monitoring system for Electric Vehicles (EVs). Our system combines **Embedded Systems, IoT, LoRa communication, sensor monitoring, and AI-based risk prediction** to identify abnormal battery conditions at an early stage.

🔹 **System Highlights:**
• Real-time monitoring of **temperature, voltage, and current**
• AI-based battery fire-risk prediction and risk scoring
• Threshold-based detection of abnormal conditions
• Automatic safety response using a relay
• Wireless communication using **LoRa**
• Live monitoring through an interactive dashboard
• Battery status and system status visualization
• Serial monitoring of real-time sensor and system data

🛠️ **Technologies & Components:**
ESP32 | LoRa | AI/ML | IoT | DHT11 | INA219 | Relay | Embedded C | Dashboard
